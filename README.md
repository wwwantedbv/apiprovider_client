# API Provider Client

API Provider is a simple one stop API to simplify the usage of other API's.

## Setup

1. Install the dependencies with Composer:
   ```bash
   composer install
   ```
2. Serve the application from the `public` directory. You can use PHP's built-in server:
   ```bash
   php -S localhost:8080 -t public
   ```

The home page will display a "Hello, world!" message using [FlightPHP](https://github.com/mikecao/flight).
